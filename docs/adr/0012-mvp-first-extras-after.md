# ADR 0012: MVP first, extras after

- Status: accepted (2026-10-23/24)

## Context
The previous rebuild stalled before its last phase.

## Decision
Ship a minimal, proven core (host hardening, gate, stacks, alerts, backups) before Dashboard v2, Home Assistant, Terraform and other extras. Each extra is its own reviewed cycle.

## Consequences
The box serves again sooner. The extras queue is explicit.
